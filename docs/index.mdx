Campaign Assistant is DME's customer-marketing stack: a web app to read the health of
your customer base, define audiences, and generate campaigns — and a versioned API
underneath it all, defined once by a shared contract and used by both halves of the
product.

Everything here is documented the [Diátaxis](https://diataxis.fr) way: four kinds of
document, each answering a different question, so you can find the page that fits
what you are doing right now.

## What the product does

- **Customers.** A full list you can filter and page, a CSV importer, and live
  aggregates on the dashboard: counts by status, spend by country, recovery rate.
- **Segments.** Name an audience — `lastActivityDays > 90`, country equals
  Senegal — and see its size counted against real customers before you save.
- **Campaigns.** Pick a segment, a channel and a tone, describe the objective, and
  let a model draft title, message and call to action for review.
- **Chat.** Ask questions about the customer base and get a streamed reply, token
  by token.
